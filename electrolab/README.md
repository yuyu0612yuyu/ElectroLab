# ElectroLab ⚡

一个面向数字电子技术初学者的免费、开源、中文交互式实验室。

## 立即使用

下载 `index.html` 后直接用浏览器打开，无需安装、账号或联网。也可以通过 GitHub Pages 发布。

## 已实现

- **74LS161**：四位同步二进制计数，异步清零、同步装载、双使能和 RCO 输出（功能级模型）。
- **555 无稳态振荡器**：输入 R1、R2、C，计算周期、频率、占空比并绘制近似方波。
- 响应式中文界面，支持手机。

## 已知限制

- 目前不是 SPICE 电路求解器，不模拟电气连接、传播延迟和模拟非理想特性。
- 555 使用经典近似公式；波形仅为理想输出示意。
- 74LS160、RS 触发器、题库等属于规划功能，尚未实现。

## 本地开发

项目采用原生 HTML/CSS/JavaScript。修改 `index.html` 并刷新浏览器即可预览。
